# 安装沾沾

官方仓库（本定制分支）：https://github.com/ccai-hhf/zhanzhan

1. 从 Releases 下载 ZIP。M 系列 Mac 选 arm64，Intel Mac 选 x86_64；芯片可在苹果菜单“关于本机”查看。
2. 解压，将“沾沾.app”拖入“应用程序”，然后打开。
3. 发布包目前没有 Apple Developer ID 签名/公证。若系统阻止打开，确认下载源和 SHA-256 后，在“系统设置 → 隐私与安全性”按苹果指引选择“仍要打开”：https://support.apple.com/102445 。无需关闭 Gatekeeper 或 SIP。
4. 默认 ⌘⇧V 或三指下滑打开，三指上滑收起。为避免系统手势冲突，将触控板“调度中心”设为四指上滑，“App Exposé”设为四指下滑或关。
5. 点击顶部“更多 → 设置”，按需开启“登录后自动启动”。这表示登录 Mac 桌面后后台运行，不需要终端。
6. 自动粘贴需要辅助功能授权。在“系统设置 → 隐私与安全性 → 辅助功能”允许沾沾，然后重试。未授权时可以正常记录、复制，再手动按 ⌘V。

运行环境：macOS 14+。完整本地运行检查在 Apple Silicon / macOS 26 上完成；Intel、旧版系统、不同触控板请参考对应 Release 的验证范围。没有触控板也可使用快捷键和菜单栏。

更新时：先退出旧版，再替换应用；`~/Library/Application Support/ZhanZhan/` 中的数据会保留。若替换后辅助功能授权失效，可在系统设置中重新添加当前安装的沾沾。

卸载时：退出沾沾，将应用移到废纸篓。历史数据不会随应用自动删除；如不需要，请自行备份后删除上面的数据目录。

源码用户请看仓库 README。Release 附带 `.sha256` 文件，可在下载目录运行 `shasum -a 256 -c ZhanZhan-版本-macOS-架构.zip.sha256` 校验 ZIP。
