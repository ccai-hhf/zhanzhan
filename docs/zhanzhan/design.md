# 沾沾：确认方案

用户已确认 02 磨砂玻璃原型，并授权实施，新增收藏文件夹。

- 保留 Maccy 原生剪贴板监听、格式处理和本地历史服务。
- 原生底部浮窗，避开 Dock，半透明材质、横向历史卡片、搜索与类型过滤。
- 卡片点击粘贴；右上角删除，可撤销；拖动排序并持久化，新复制内容到最左边。
- 收藏独立保存内容快照，历史删除/清理不影响收藏。支持文字、链接和剪贴板图片。
- 一级文件夹：新建、重命名、删除、移动收藏；删除文件夹仅解除分类，不删除内容。
- 收藏支持手动新增、编辑标题/文本、复制、打开 HTTP(S) 链接、拖动排序。
- 独立应用名“沾沾”、Bundle ID `local.zhanzhan.clipboard`、数据目录 `ZhanZhan`，不读取/迁移官方 Maccy 数据，不连接官方更新源。
- 保留 MIT 声明；第一版为本机签名构建，不宣称公证/外部分发验证。

验证：数据读写和失败保护、文件夹删除不丢收藏、排序和重启、真实原生界面、复制捕获与粘贴权限边界。

构建决策：系统没有完整 Xcode，但有 Swift 6.3 + macOS SDK，优先使用 Swift Package Manager。Xcode UI 测试不能以源码检查替代。
